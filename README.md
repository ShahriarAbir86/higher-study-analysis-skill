# 🎓 Higher Study Analysis — Claude Skill

যেকোনো দেশের নাম ও নিজের academic background দিলে এই Claude Skill একটা 
complete higher study guide তৈরি করে — Word (.docx) file হিসেবে।

## কী কী থাকে?

13-section সম্পূর্ণ guide:
- Scholarship details (fully verified)
- Cost breakdown — local currency + BDT
- University list (field-specific)
- Career paths + PR roadmap
- Documents checklist (Bangladesh-specific)
- Month-by-month prep timeline
- SOP guide + professor email template
- Interview preparation

## কোন কোন দেশের জন্য কাজ করে?

Korea (GKS), Germany (DAAD), Japan (MEXT), Australia, UK (Chevening), 
Canada, Netherlands, Sweden — এবং যেকোনো দেশ।

## Install করার পদ্ধতি

**Requirements:** Claude.ai account (Free plan-এও কাজ করে)

1. [`higher-study-analysis.skill`](./higher-study-analysis.skill) ফাইলটা download করো
2. [claude.ai](https://claude.ai) → Settings → Skills → Upload
3. New chat-এ লেখো: **"জাপানে Masters করতে চাই"**
4. Background দাও → Word file download করো

## কীভাবে কাজ করে?

Skill activate হলে Claude তোমার কাছে জানতে চাইবে:

| প্রশ্ন | Example |
|---|---|
| Degree ও Subject | BSc in CSE / BEng in IPE |
| University ও Country | KUET, Bangladesh |
| Graduation কবে | August 2026 |
| Research Interest | AI + Manufacturing |
| লক্ষ্য | Fully funded Masters → PR |
| Target Country | Japan / Germany / Korea |

তারপর web search করে verified data দিয়ে complete .docx তৈরি করবে।
